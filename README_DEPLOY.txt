วิธีเอาขึ้นเซิร์ฟเวอร์ (PHP + SQLite — โยนไฟล์แล้วใช้ได้เลย)
============================================================

1) อัปโหลดทั้งโฟลเดอร์นี้ขึ้นเซิร์ฟเวอร์ (เช่น public_html/sport/):
   index.php / score.php / admin.php / api.php / lib/ / data/

2) ตั้งสิทธิ์ให้ PHP เขียนได้ 2 จุด (สร้างไฟล์ DB + เก็บโลโก้สถาบัน):
   chmod 775 data uploads  (ถ้าใช้ FTP: คลิกขวา data และ uploads → permissions 775)

3) เซิร์ฟเวอร์ต้องมี extension pdo_sqlite (โฮสต์ PHP ทั่วไปมีอยู่แล้ว ถ้าไม่มีจะมีข้อความบอกบนหน้าเว็บ)

4) เปิดเว็บครั้งแรก:
   - หน้าแรก:  https://โดเมนของคุณ/sport/index.php
   - หลังบ้าน: https://โดเมนของคุณ/sport/admin.php
     ครั้งแรก: admin / Admin1234  → เข้าแล้วตั้งรหัสใหม่ทันที (รหัสต้องมีอักษร+ตัวเลข 6+ ตัว)

ขั้นตอนใช้งานวันแข่ง
====================
1. admin เพิ่มสถาบัน / กีฬา / แมตช์ ที่ admin.php
2. กดปุ่ม QR ของแต่ละคู่ → พิมพ์ไปติดข้างสนาม
3. กรรมการสแกน QR → กรอกสกอร์ได้เลยไม่ต้องใส่รหัส → กด "จบการแข่งขัน" (ล็อกทันที)
4. แมตช์ที่ล็อกแล้ว manager แก้ไม่ได้ — admin กด "ปลดล็อก" ได้คนเดียว
5. เพิ่ม manager: ตั้งชื่อ + username + รหัส + ผูก 1 กีฬา (ทายรหัสผิด 5 ครั้งล็อก 5 นาที)
6. หน้าแรก index.php รีเฟรชเองทุก 1 นาที เห็นผลสดทั้งสนาม

สำรองข้อมูล: ก็อปไฟล์ data/app.sqlite เก็บไว้ไฟล์เดียวจบ

ข้อมูล demo: data/app.demo.sqlite (รหัส demo: admin/Admin1234, kru1+2/Demo1234)
  ใช้โดย: copy app.demo.sqlite เป็น app.sqlite (ห้ามทับไฟล์จริงที่มีรหัสใช้งานอยู่)
